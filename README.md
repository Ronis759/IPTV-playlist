# IPTV-playlist

Рабочие IPTV-каналы, разложенные по папкам-категориям. Каналы проверяются автоматически, отвалившиеся заменяются другими.

**Ссылка на плейлист:**

```
https://ronis759.github.io/IPTV-playlist/IPTV-playlist.m3u
```

Сайт-каталог: https://ronis759.github.io/IPTV-playlist/

---

## Категории

| Категория | Файл |
|---|---|
| Базовые (центральные, новостные, общественные) | `playlists/basic.m3u` |
| Беларусь | `playlists/by.m3u` |
| Развлекательные | `playlists/entertainment.m3u` |
| Познавательные | `playlists/education.m3u` |
| Кино | `playlists/movies.m3u` |
| Музыка | `playlists/music.m3u` |
| Детские | `playlists/kids.m3u` |
| Спорт | `playlists/sport.m3u` |
| Разное (всё, что не попало в другие группы) | `playlists/other.m3u` |

- `IPTV-playlist.m3u` — всё сразу, по категориям.
- `streams/<канал>.m3u` — отдельный файл на каждый канал.

## Как подключить

- **VLC / OTT Navigator / IPTV Smarters / TiviMate**: добавьте плейлист по ссылке выше.
- **Браузер**: [IPTV Online](https://ronis759.github.io/IPTV-online/) → «Плейлисты» → вставьте ссылку.
- **Noxis-IPTV**: «Добавить плейлист» → «По ссылке».

## Что внутри и чего нет

- Каналы из открытых источников (iptv-org, Free-TV): Россия, Беларусь, Казахстан, Украина, Прибалтика и другие — в том числе русскоязычные.
- Только `https`-потоки — работают в браузере и на мобильных.
- Каналы с архивом помечены `#EXTVLCOPT:vlc-loop` (метка «архив» в каталоге) и стоят первыми.
- Мёртвые ссылки, гео-«заглушки» и медленные потоки (дольше 3 секунд на запуск) не попадают в плейлист.

## Как обновляется

Каждый день в 08:17 по Москве GitHub Actions запускает проверку (`scripts/refresh.mjs`):

1. Каждый канал проверяется вживую: манифест → медиаплейлист → первый видеофрагмент, наличие CORS, время отклика.
2. Живые и быстрые остаются (до 6 секунд на запуск).
3. Отвалившиеся или медленные ищут замену: сначала другой рабочий поток того же канала, затем аналогичный канал из той же категории.
4. Обновляются плейлисты, каталог сайта и отчёт `data/update-report.json`.
5. Изменения коммитятся автоматически.

Запустить вручную:

- на GitHub: вкладка **Actions** → **Обновление плейлиста** → **Run workflow**;
- на компьютере: двойной щелчок по **`update.bat`** (проверит каналы, заменит отвалившиеся и отправит изменения на GitHub).

Полная пересборка с нуля — **`build.bat`**.

## Локальная пересборка

Нужен Node.js 22+.

```powershell
node scripts/build.mjs        # полная сборка с нуля (каталог iptv-org + проверка)
node scripts/refresh.mjs      # проверка текущего плейлиста и замены
node scripts/validate.mjs     # контроль формата M3U
```

Настройки сборки:

```powershell
node scripts/build.mjs --limit-per-channel=3 --concurrency=40
```

## Структура

```
IPTV-playlist.m3u        общий плейлист
playlists/               по категориям
streams/                 по одному каналу
data/channels.json       каталог для сайта
data/summary.json        сводка (сколько каналов, сколько с архивом)
data/update-report.json  отчёт последнего обновления
scripts/                 сборка, обновление, проверка формата
index.html, assets/      сайт-каталог
.github/workflows/       ежедневное автообновление
```

## Источники

Открытые публичные каталоги: [iptv-org](https://github.com/iptv-org/iptv) (каталог каналов и потоков, логотипы), [Free-TV](https://github.com/Free-TV/IPTV), плейлисты по странам RU/BY/KZ.

Ссылки остаются собственностью вещателей — проект только собирает и проверяет открытые потоки.
